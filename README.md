# Shoe Size Prediction Model

## Overview
This repository features an end-to-end Machine Learning pipeline designed to predict individual shoe sizes using biometric and physical features. The project covers complete exploratory data analysis (EDA), continuous target discretization/rounding, and evaluation using confusion matrices, classification metrics, and Seaborn heatmaps.

## Key Features
- **Data Preprocessing & Encoding:** Normalization, feature scaling, and handling missing data.
- **Model Training:** Regression and multi-class classification models trained to estimate shoe sizes.
- **Model Evaluation:** Evaluated using Mean Squared Error (MSE), R² score, and visual confusion matrix heatmaps (`sklearn` & `seaborn`).
- **Interactive Jupyter Workflow:** Cell-by-cell execution with error diagnostics and evaluation visualizers.

## Tech Stack
- **Languages:** Python
- **Libraries:** NumPy, Pandas, Scikit-Learn, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook / Kaggle Notebooks
